# 项目演示步骤

## 启动

```powershell
python -m pip install -r requirements.txt
python scripts/prepare_data.py
python scripts/train_model.py
python scripts/evaluate_ranking.py
python app.py
```

打开 <http://127.0.0.1:5000>。

## 演示一：数据分析岗位

1. 点击“加载示例简历”，第一次显示数据分析示例；
2. 只勾选“数据分析”；
3. 招聘类型选择“实习”，经验选择“应届/在校”；
4. 点击“开始分析”；
5. 展示技能画像、筛选后岗位数及匹配分；
6. 如果有“简历中未找到”的技能，点击其中一个并确认，观察结果重新排序；
7. 点击某个岗位的“该岗位匹配不准确”，说明该反馈会在后续分析中降权。

## 演示二：前端与嵌入式示例

1. 再次点击“下一个示例”，切换到前端示例；
2. 只勾选“前端开发”并重新分析；
3. 再切换到嵌入式示例，只勾选“嵌入式开发”；
4. 对比三个方向识别出的技能和推荐岗位。

## 演示三：自定义 JD

1. 展开“分析一段自定义 JD”；
2. 粘贴 `demo/custom_jd.txt`；
3. 运行分析；
4. 展示模型预测方向、必备技能覆盖和未找到技能；
5. 如果置信度较低，从下拉框确认方向并重新分析。

## 演示四：浏览完整岗位库

1. 设置岗位方向、城市、招聘类型、经验和发布时间；
2. 点击“应用当前筛选”；
3. 展示岗位总数和当前页；
4. 点击“加载更多”，验证分页；
5. 选择一个筛选过严的组合，展示“放宽条件”提示。

## 演示五：PDF 上传

1. 上传一份文字型 PDF 简历；
2. 确认系统提取出与文本粘贴方式一致的主要技能；
3. 如果 PDF 是扫描件，展示“需要 OCR 或粘贴文本”的提示。

## 建议录屏节点

- 00:00—00:20：项目目标和本地运行状态；
- 00:20—01:10：数据分析简历分析与筛选；
- 01:10—01:40：技能人工确认与重新排序；
- 01:40—02:10：自定义 JD 与低置信度方向确认；
- 02:10—02:40：岗位库分页和筛选；
- 02:40—03:00：报告指标、复现命令与安全边界。
